# 🍽️ Zomato Order Analysis Dashboard

An interactive **Power BI dashboard** designed to analyze food delivery data across multiple cities and restaurants. This project provides insights into sales performance, restaurant rankings, customer satisfaction, and delivery efficiency through data visualization and business intelligence.

## 📌 Project Overview

The project focuses on transforming raw food delivery data into meaningful business insights. Using Power BI, Power Query, and DAX, the dashboard enables users to monitor key performance indicators (KPIs), explore trends, and evaluate restaurant and operational performance.

## 🎯 Problem Statement

Food delivery businesses generate large amounts of data related to orders, revenue, restaurants, customer ratings, and delivery times. Analyzing this data manually makes it difficult to identify trends, evaluate performance, and understand customer preferences.

This project addresses the problem by developing an interactive dashboard that consolidates key business metrics and presents them through clear, easy-to-understand visualizations.

## 📊 Dataset Overview

The analysis is based on three interconnected datasets:

| Dataset | Description |
|---|---|
| Orders | Contains 2,500+ food delivery order records |
| Restaurants | Contains information about 20 restaurants |
| Cities | Contains information about 10 cities |

**Total coverage:** 2,500+ orders across 10 cities and 20 restaurants.

## 🛠️ Tools & Technologies

- **Power BI** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and KPI calculations
- **Microsoft Excel** – Dataset preparation and storage

## ⚙️ Data Preparation & Modeling

- Removed duplicate order records and checked for missing values.
- Cleaned and transformed data using Power Query.
- Standardized text fields and assigned appropriate data types.
- Established relationships between Orders, Restaurants, and Cities tables.
- Created DAX measures to calculate key business metrics.

## 📈 Key Performance Indicators (KPIs)

The dashboard tracks the following metrics:

- **Total Orders** – Overall number of orders.
- **Total Revenue** – Revenue generated from orders.
- **Average Order Value** – Average value per order.
- **Average Delivery Time** – Average time taken to deliver orders.
- **Average Customer Rating** – Overall customer rating.
- **Cancellation Rate** – Percentage of orders that were cancelled.

## 📊 Dashboard Features

### 1. Sales Overview
- Tracks overall orders and revenue.
- Analyzes revenue across cities and cuisines.
- Displays order trends over time.
- Examines payment method and order status distribution.

### 2. Restaurant & Cuisine Analysis
- Identifies top-performing restaurants.
- Compares restaurant performance by revenue and order volume.
- Analyzes cuisine-wise revenue and order distribution.
- Evaluates restaurant ratings.

### 3. Customer & Delivery Analysis
- Compares customer ratings across cities.
- Analyzes average delivery time by city.
- Examines customer rating distribution.
- Explores the relationship between delivery time and customer ratings.
- Evaluates delivery performance across restaurants.

## 🔍 Key Business Questions

The dashboard helps explore questions such as:

1. Which cities generate the highest revenue?
2. Which restaurants contribute the most to total revenue?
3. Which cuisines receive the highest number of orders?
4. How does delivery time vary across cities?
5. How do customer ratings differ across locations?
6. Which payment methods are most commonly used?
7. What percentage of orders are cancelled?

## 🎛️ Interactive Features

- Dynamic slicers for City, Cuisine, Restaurant, Payment Method, Order Status, and Order Date.
- Interactive charts and visualizations.
- Cross-filtering between dashboard visuals.
- Multiple dashboard pages for focused analysis.


## 🚀 How to Run the Project

1. Clone or download this repository.
2. Download and install Microsoft Power BI Desktop.
3. Open the `.pbix` file in Power BI Desktop.
4. If required, update the dataset source path.
5. Refresh the data to load the latest dataset.
6. Explore the dashboard using the interactive slicers and visualizations.

Developed a three-page interactive business intelligence dashboard that transforms 2,500+ food delivery records into actionable analytical views. The dashboard enables exploration of sales trends, restaurant performance, customer satisfaction, and delivery efficiency to support data-driven decision-making.
